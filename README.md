# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview

This project presents a Sales Performance Dashboard developed using Power BI to analyze retail sales data from the Sample Superstore dataset. The dashboard provides insights into overall sales performance, profit generation, regional sales distribution, and category-wise sales trends.

The objective of this project is to transform raw business data into meaningful visual insights that support data-driven decision-making.

---

## 🎯 Objectives

- Analyze overall sales and profit performance.
- Identify top-performing product categories.
- Compare sales distribution across regions.
- Create interactive visualizations for business insights.
- Develop a professional business intelligence dashboard using Power BI.

---

---

## 🔍 Key Insights

- The **West Region** generated the highest sales revenue.
- **Technology** emerged as the top-performing product category.
- Sales performance varies significantly across different regions.
- The dashboard enables quick identification of business trends and opportunities.
